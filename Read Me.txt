# 🌤️ Weather CLI - OpenWeatherMap

A simple Python command-line app that fetches real-time weather information for any city using the OpenWeatherMap API.

## 📦 Features

- 🌍 Get current weather by city name  
- 🌡️ Shows temperature, weather condition, humidity, and wind speed  
- ❌ Handles common errors like invalid city or network issues  

## 🚀 Requirements

- Python 3.7+
- `requests` library

## 🔧 Installation

```bash
git clone https://github.com/your-username/weather-cli.git
cd weather-cli
pip install -r requirements.txt
```

## 🔑 Setup

1. Go to [OpenWeatherMap](https://openweathermap.org/api) and sign up for a free account.
2. Get your API key from the dashboard.
3. Open `main.py` and replace this line:
   ```python
   API_KEY = 'your_api_key_here'
   ```
   with:
   ```python
   API_KEY = 'your_actual_api_key'
   ```

## 🧪 Usage

```bash
python main.py
```

Then enter a city name when prompted.
